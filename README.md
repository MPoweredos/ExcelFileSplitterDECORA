# ExcelFileSplitterDEC

Dzieli jeden raport Excela na osobne pliki dla poszczególnych odbiorców — tak, że dane pozostałych wartości w pliku fizycznie nie istnieją.
Nie są ukryte, nie są odfiltrowane, nie siedzą w cache'u tabeli przestawnej ani w XML wykresu. 
Każdy gotowy plik jest po zapisaniu otwierany ponownie i sprawdzany, jeżeli nie przeszedł kontroli, dostaje w nazwie _NIE_WYSYLAC.
